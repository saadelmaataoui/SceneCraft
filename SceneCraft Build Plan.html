SceneCraft Build Plan

Drop in a silent clip. SceneCraft finds every thing on screen that should make a sound, tracks it frame by frame, generates and ranks the foley, places each hit on the frame where it happens, and mixes the result. Then it watches and listens to its own mix and fixes what is off. This page covers the architecture, the build order and the 48-hour plan for a team of two.

Before you write code

Six changes to the Gemini plan

The Gemini chat was built on an older picture of Meta's stack. Meta's Model API (dev.meta.ai) now serves a video-native model and a hosted SAM, which removes most of the hard infrastructure and makes real sync possible in a weekend.

  • WasLlama 3.2 Vision on a grid of extracted frames

    Nowmuse-spark-1.3 reads the whole mp4. The Model API takes video (with its audio track) directly and returns output constrained to your JSON schema. It speaks the OpenAI SDK at https://api.meta.ai/v1. No frame extraction, no grids.

  • WasSAM 2 as a visual effect, run on a laptop

    NowSAM 3.1 drives the timing. It is hosted on the same API (sam-3.1), takes a noun like "shoe", and streams a box and mask per object per frame. Heel strikes and slams are read from those boxes. No GPU needed, $0.20 per 1,000 frames.

  • WasOne AudioGen prompt for the whole clip

    NowOne-shots placed on detected frames, a speed-driven layer for continuous sounds, and an ambience bed. One clip-length sound cannot line up with footsteps, and sync is the product.

  • WasNo quality control

    NowTwo Meta judges. Audiobox Aesthetics ranks four AudioGen takes per sound. Muse Spark then watches and listens to the finished mix and asks for one round of fixes.

  • WasGradio only

    NowA custom UI on Meta's own SAM renderer. Meta ships @meta-sam/parser, @meta-sam/graphics, @meta-sam/video and @meta-sam/react for drawing streamed masks, so the live overlay is cheap to build. A Gradio wrapper over the CLI stays as a 30-minute fallback.

  • WasLlama Stack, Replicate, Together, Modal, all at once

    NowTwo services. The Meta Model API for Muse Spark and SAM 3.1, and one Modal app for AudioGen and Audiobox Aesthetics, the two open-weight models that need a GPU.

The core idea

Muse Spark knows what makes sound and roughly when. SAM 3.1 knows exactly where things are on every frame. Neither can sync foley alone. Snapping the language model's rough times onto the vision model's motion events is the technical story you tell the judges.

The contract between you two

The cue sheet

In post-production a cue sheet lists every sound and where it goes. Here it is the one JSON document every stage reads or writes, the thing you cache, and the thing the UI renders. Agree on it in hour one so Person B can build the UI against a hand-written copy while the pipeline is still broken.

  • Times are seconds from clip start. SAM frame indexes count frames of sam.mp4, so t = frame / sam_fps. Convert once, in sync.py, and nowhere else.
  • category uses real foley terms: feet (footsteps), moves (cloth and body), specifics (props). The UI draws one lane per category, so a sound editor would recognise the layout.
  • origin says who placed each event: snapped (both models agree), sam_only (motion found a hit Muse Spark missed), muse_only (no motion match). Colour ticks by it in the UI. It shows judges the two-model logic at a glance.

First two hours: four spikes

A · 45 min

Ingest: fix the frame rate, make two proxies

Phones record variable frame rate, which makes events drift against the picture. Convert to a constant rate first, then derive both proxies from that master. Cap uploads at 15 seconds here.

ingest.py runs thesebash
# 1. Constant-frame-rate master, first 15 s only
ffmpeg -y -i take.mov -t 15 -vf "fps=30,scale=-2:1080" -an -c:v libx264 -crf 18 -pix_fmt yuv420p master.mp4

# 2. Clean proxy for SAM 3.1. 15 fps halves the frame bill and is plenty for footsteps.
ffmpeg -y -i master.mp4 -vf "fps=15,scale=-2:720" -c:v libx264 -pix_fmt yuv420p sam.mp4

# 3. Proxy for Muse Spark with the clock burned in, so it can read times off the picture
ffmpeg -y -i master.mp4 -vf "fps=15,scale=-2:480,drawtext=text='%{pts\:hms}':x=12:y=12:fontsize=26:fontcolor=white:box=1:boxcolor=black@0.6" -c:v libx264 -pix_fmt yuv420p muse.mp4

# Sizes for sync.py
ffprobe -v error -select_streams v:0 -show_entries stream=width,height,nb_frames -of json sam.mp4

Both Meta endpoints accept mp4 only. drawtext needs a font: install fonts-dejavu-core in the Modal image; on Windows add fontfile=C\\:/Windows/Fonts/arial.ttf.

A · 2 h · Meta Model API

Spotting with Muse Spark

A spotting session is where a supervisor watches the cut and decides what needs sound. Muse Spark does that here and returns it in a schema you control. Most of your quality comes from the brief, so iterate on it with the six clips.

scenecraft/spotting.pypython · pip install openai
import json, os
from openai import OpenAI

client = OpenAI(base_url="https://api.meta.ai/v1", api_key=os.environ["MODEL_API_KEY"])
MODEL = "muse-spark-1.3"

def upload(path):
    with open(path, "rb") as f:
        return client.files.create(purpose="user_data", file=f).id

SOURCE = {
    "type": "object", "additionalProperties": False,
    "required": ["id", "sam_concept", "category", "mode", "sound_prompt", "approx_times_s"],
    "properties": {
        "id": {"type": "string"},
        "sam_concept": {"type": "string", "description": "one short noun phrase, e.g. 'shoe'"},
        "category": {"type": "string", "enum": ["feet", "moves", "specifics"]},
        "mode": {"type": "string", "enum": ["impact", "continuous"]},
        "sound_prompt": {"type": "string"},
        "approx_times_s": {"type": "array", "items": {"type": "number"}},
    },
}
SPOTTING = {
    "type": "object", "additionalProperties": False, "required": ["scene", "sources"],
    "properties": {
        "scene": {
            "type": "object", "additionalProperties": False,
            "required": ["location", "acoustics", "ambience_prompt"],
            "properties": {k: {"type": "string"} for k in ["location", "acoustics", "ambience_prompt"]},
        },
        "sources": {"type": "array", "items": SOURCE},
    },
}

BRIEF = """You are a foley supervisor running a spotting session on a silent clip.
The clock burned into the top-left corner is the clip time. Read every time from it.
List each on-screen thing that should make a sound:
- sam_concept: ONE short noun phrase a segmentation model can find ("shoe", "door", "mug"). Never a list.
- category: feet (footsteps), moves (cloth and body movement), specifics (props and objects).
- mode: impact for discrete hits, continuous for sound that lasts while it moves.
- sound_prompt: ONE isolated hit (impact) or a steady texture (continuous). Name the material,
  surface, intensity and mic distance. End with: isolated, dry, no music, no speech.
- approx_times_s: when each hit happens, in seconds. Empty for continuous sources.
scene.ambience_prompt: the room tone or background for this place, ending with: no music, no speech."""

def spot(muse_mp4):
    resp = client.responses.create(
        model=MODEL,
        instructions=BRIEF,
        input=[{"type": "message", "role": "user", "content": [
            {"type": "input_text", "text": "Spot this clip."},
            {"type": "input_video", "file_id": upload(muse_mp4)},
        ]}],
        text={"format": {"type": "json_schema", "name": "SpottingList", "strict": True, "schema": SPOTTING}},
    )
    print(resp.usage)  # spike 1: this is how you price a clip
    return json.loads(resp.output_text)
  • The schema follows Meta's strict subset: plain object at the root, additionalProperties: false on every object, every key listed in required, no recursion.
  • Meta's structured-output page shows a full example only for Chat Completions (response_format). If text.format on Responses gives you trouble, switch to Chat Completions with a video_url content part (a base64 data URL works up to 50 MB).
  • Good AudioGen prompts are short and physical. "single footstep on loose gravel, sneaker, close mic, isolated, dry, no music, no speech" works. "A man walks on a path" does not.

A · 2 h · Meta Model API

Tracking with SAM 3.1

One request per concept: Meta's docs say lists like "shoe, door" return zero matches. Run the requests concurrently. Each streamed line is one frame: <Nf>, then records of id<|box;…|><|mask;…|> separated by commas. Timing only needs the boxes. Forward the raw lines to the browser and let Meta's JS parser decode masks there.

scenecraft/tracking.pypython
import re
from scenecraft.spotting import client

FRAME = re.compile(r"<(\d+)f>")
BOX = re.compile(r"(\d+)<\|box;([^|]+)\|>")   # boxes are all the timing needs

def track(file_id, concept, on_line=None):
    """Returns {object_id: [(frame, x1, y1, x2, y2), ...]} in sam.mp4 pixels."""
    tracks = {}

    def handle(line):
        m = FRAME.match(line)
        if not m:
            return
        if on_line:
            on_line(concept, line)  # the UI decodes masks with @meta-sam/parser
        frame = int(m.group(1))
        for obj, kv in BOX.findall(line):
            d = dict(p.split("=", 1) for p in kv.split(";"))
            tracks.setdefault(int(obj), []).append(
                (frame, float(d["x1"]), float(d["y1"]), float(d["x2"]), float(d["y2"])))

    with client.responses.stream(
        model="sam-3.1",
        input=[{"type": "message", "role": "user", "content": [
            {"type": "input_text", "text": concept},  # one noun phrase, never a list
            {"type": "input_video", "file_id": file_id},
        ]}],
    ) as stream:
        for event in stream:
            if event.type == "response.output_text.delta":
                for line in event.delta.splitlines():  # docs: one delta per frame line
                    handle(line.strip())

    for t in tracks.values():
        t.sort()  # frame indexes can skip and arrive out of order
    return tracks
  • Upload sam.mp4 once with spotting.upload and reuse the file_id for every concept.
  • Python alternative to the regex: pip install meta-sam-parser, which ports Meta's parser and exposes decode_mask_to_raster.
  • Object ids are stable within a response but can change after full occlusion. For impacts you merge all tracks of a concept anyway, so a swap does no harm.

A · 3 h

Sync: where the hits are

A sudden stop makes a sound: a heel strike, a mug set down, a door meeting its frame. So an impact is a peak in deceleration of the tracked box. Continuous sources get a level that follows speed. Then each of Muse Spark's rough times snaps to the strongest motion peak near it.

scenecraft/sync.pypython · numpy, scipy
import numpy as np
from scipy.signal import savgol_filter, find_peaks

FPS = 15  # frame rate of sam.mp4: SAM frame indexes are proxy frames

def motion(track, w, h):
    """Box track -> per-frame centre x, size, speed. Gaps are interpolated."""
    f = np.array([r[0] for r in track])
    b = np.array([r[1:] for r in track], dtype=float)
    frames = np.arange(f[0], f[-1] + 1)
    x1, y1, x2, y2 = (np.interp(frames, f, b[:, i]) for i in range(4))
    cx, bottom = (x1 + x2) / 2, y2              # bottom edge: where contact happens
    area = (x2 - x1) * (y2 - y1) / (w * h)      # share of the frame: a distance cue
    if len(frames) >= 7:
        cx, bottom = savgol_filter(cx, 7, 2), savgol_filter(bottom, 7, 2)
    speed = np.hypot(np.gradient(cx), np.gradient(bottom)) * FPS / h  # frame-heights per second
    return frames, cx, area, speed

def detect_impacts(track, w, h, min_gap_s=0.18):
    frames, cx, area, speed = motion(track, w, h)
    if len(frames) < 7:
        return []
    decel = np.clip(-np.gradient(speed), 0, None)
    if decel.max() == 0:
        return []
    peaks, _ = find_peaks(decel, height=0.25 * decel.max(), distance=max(1, round(min_gap_s * FPS)))
    return [{
        "t": frames[p] / FPS,
        "frame": int(frames[p]),
        "pan": float(np.clip(cx[p] / w * 2 - 1, -1, 1)),
        "gain_db": float(np.clip(10 * np.log10(area[p] / 0.02 + 1e-6), -12, 3)),
        "strength": float(decel[p] / decel.max()),
    } for p in peaks]

def snap(approx_times, detected, window_s=0.35):
    """Muse Spark says roughly when; SAM motion says exactly when."""
    events, used = [], set()
    for t in approx_times:
        near = [i for i, d in enumerate(detected) if abs(d["t"] - t) <= window_s and i not in used]
        if near:
            i = max(near, key=lambda i: detected[i]["strength"])
            used.add(i)
            events.append({**detected[i], "origin": "snapped"})
        else:
            events.append({"t": t, "frame": round(t * FPS), "pan": 0.0, "gain_db": -6.0,
                           "strength": 0.5, "origin": "muse_only"})
    events += [{**d, "origin": "sam_only"} for i, d in enumerate(detected)
               if i not in used and d["strength"] > 0.6]
    return sorted(events, key=lambda e: e["t"])

def envelope(track, w, h, n_frames):
    """Continuous sources (cloth, rolling): the level follows speed."""
    frames, _, _, speed = motion(track, w, h)
    env = np.zeros(n_frames)
    env[frames] = np.clip(speed / 0.5, 0, 1)  # 0.5 frame-heights per second = full level
    return env

build_cue_sheet ties it together: for each impact source, merge detect_impacts over all its tracks, then snap against approx_times_s. For each continuous source, take the envelope of its largest track. Write the result into events and keep the envelopes beside the cue sheet.

Tune on real clips

Plot bottom, speed and decel for the gravel clip with the detected peaks marked. Ten minutes of plotting saves hours of guessing. The two numbers you will tune are the 0.25 peak height and the 0.35 s snap window.

B · 3 h · Modal GPU

Sourcing: AudioGen takes, ranked by Audiobox Aesthetics

A foley artist records several takes and the editor keeps the best. Do the same: four AudioGen takes per sound in one batch, scored by Audiobox Aesthetics, the top three kept as variants so repeated footsteps never sound identical.

modal_audio.pydeploy once: modal deploy modal_audio.py
import io
import modal

app = modal.App("scenecraft-audio")
weights = modal.Volume.from_name("scenecraft-weights", create_if_missing=True)

# Two images on purpose: audiocraft pins torch 2.1, audiobox_aesthetics needs torch 2.2 or later
gen_image = (modal.Image.debian_slim(python_version="3.10")
             .apt_install("ffmpeg", "git")
             .pip_install("audiocraft", "soundfile")
             .env({"HF_HOME": "/weights/hf"}))
judge_image = (modal.Image.debian_slim(python_version="3.10")
               .pip_install("audiobox_aesthetics", "soundfile")
               .env({"HF_HOME": "/weights/hf"}))

def wav_bytes(x, sr):
    import soundfile as sf
    buf = io.BytesIO()
    sf.write(buf, x, sr, format="WAV")
    return buf.getvalue()

@app.cls(gpu="L4", image=gen_image, volumes={"/weights": weights}, scaledown_window=600)
class Foley:
    @modal.enter()
    def load(self):
        from audiocraft.models import AudioGen
        self.model = AudioGen.get_pretrained("facebook/audiogen-medium")

    @modal.method()
    def takes(self, prompt: str, seconds: float, k: int = 4) -> list[bytes]:
        self.model.set_generation_params(duration=seconds)
        wavs = self.model.generate([prompt] * k)  # k different takes: [k, 1, samples] at 16 kHz
        return [wav_bytes(w[0].cpu().numpy(), self.model.sample_rate) for w in wavs]

@app.cls(gpu="T4", image=judge_image, volumes={"/weights": weights}, scaledown_window=600)
class Judge:
    @modal.enter()
    def load(self):
        from audiobox_aesthetics.infer import initialize_predictor
        self.predictor = initialize_predictor()

    @modal.method()
    def score(self, clips: list[bytes]) -> list[dict]:
        import soundfile as sf, torch
        batch = []
        for c in clips:
            x, sr = sf.read(io.BytesIO(c), dtype="float32")
            batch.append({"path": torch.from_numpy(x)[None], "sample_rate": sr})
        return self.predictor.forward(batch)  # one dict per clip: CE, CU, PC, PQ
scenecraft/sourcing.pycalled from the web app
import modal

Foley = modal.Cls.from_name("scenecraft-audio", "Foley")
Judge = modal.Cls.from_name("scenecraft-audio", "Judge")

SECONDS = {"impact": 1.5, "continuous": 5.0, "ambience": 10.0}

async def source(prompt, mode, keep=3):
    clips = await Foley().takes.remote.aio(prompt, SECONDS[mode], 4)
    scores = await Judge().score.remote.aio(clips)
    ranked = sorted(zip(scores, clips), key=lambda sc: sc[0]["PQ"] + sc[0]["CU"], reverse=True)
    return [clip for _, clip in ranked[:keep]]  # best takes become round-robin variants
  • Ranking key: PQ (production quality) plus CU (content usefulness) favours clean, usable takes. Show the scores in the UI next to each take.
  • Check in spike 3 that forward returns a list of dicts. The README shows the four keys but not the Python return type.
  • AudioGen outputs 16 kHz mono. The mixer upsamples to 48 kHz; the ambience bed covers most of the missing top end. Do not claim studio quality.
  • Licences: AudioGen weights are CC-BY-NC 4.0, which is fine for a hackathon. If judges ask about a commercial version, say you would license or retrain the generator.

A or B · 2 h

Mix: place, pan, vary, master

Three details make it sound edited rather than generated: trim each take so its attack is sample zero (the hit lands on its frame), vary pitch and level slightly per hit, and pan by where the object is on screen.

scenecraft/mix.pypython · pip install soundfile pyloudnorm scipy
import io
from collections import defaultdict
import numpy as np, soundfile as sf, pyloudnorm as pyln
from scipy.signal import resample_poly
from scenecraft.sync import FPS

SR = 48_000

def load(wav_bytes):
    """AudioGen output (16 kHz mono) -> 48 kHz float32."""
    x, sr = sf.read(io.BytesIO(wav_bytes), dtype="float32")
    return resample_poly(x, SR, sr).astype(np.float32)

def trim_to_transient(x, thresh_db=-30):
    """Start the take at its attack so the hit lands on its frame."""
    start = int(np.argmax(np.abs(x) > np.abs(x).max() * 10 ** (thresh_db / 20)))
    x = x[max(0, start - int(0.005 * SR)):].copy()
    fade = int(0.002 * SR)
    x[:fade] *= np.linspace(0, 1, fade)
    return x

def place(bus, x, t, pan, gain_db):
    i = int(t * SR)
    if i >= len(bus):
        return
    j = min(len(bus), i + len(x))
    g, a = 10 ** (gain_db / 20), (pan + 1) * np.pi / 4  # constant-power pan
    bus[i:j, 0] += x[: j - i] * g * np.cos(a)
    bus[i:j, 1] += x[: j - i] * g * np.sin(a)

def render(events, takes, textures, ambience, duration_s):
    """takes: {source_id: [48 kHz arrays]}; textures: {source_id: (array, per-frame envelope)}."""
    n = int(duration_s * SR)
    stems = defaultdict(lambda: np.zeros((n, 2), np.float32))
    rng, count = np.random.default_rng(7), defaultdict(int)
    for e in events:
        sid = e["source_id"]
        x = trim_to_transient(takes[sid][count[sid] % len(takes[sid])])  # round-robin takes
        count[sid] += 1
        rate = 2 ** (rng.uniform(-1, 1) / 12)                            # up to 1 semitone either way
        x = resample_poly(x, 1000, round(1000 * rate)).astype(np.float32)
        place(stems[sid], x, e["t"], e["pan"], e["gain_db"] + rng.uniform(-1.5, 1.5))
    for sid, (tex, env) in textures.items():
        level = np.interp(np.arange(n) / SR, np.arange(len(env)) / FPS, env)
        stems[sid] += (np.resize(tex, n) * level * 0.5)[:, None]
    stems["ambience"] += (np.resize(ambience, n) * 10 ** (-18 / 20))[:, None]
    master = sum(stems.values())
    k = 10 ** ((-16.0 - pyln.Meter(SR).integrated_loudness(master)) / 20)
    return {s: v * k for s, v in stems.items()}, np.clip(master * k, -1, 1)  # same gain, so solo matches the mix

            },
        }},
    },

Apply one fix pass, then score again and show both numbers in the UI:

  • wrong_sound: regenerate that source with fix_prompt (Step 5) and re-mix.
  • too_loud or too_quiet: move that source by 4 dB.
  • unwanted: drop that source's events within 0.25 s of time_s.
  • off_sync: re-snap that source with a 0.15 s window.
  • missing: show it in the QC panel only. Adding a new source mid-run is out of scope.

Trust QC for meaning (wrong material, missing source, a sound that should not be there). Frame-level timing comes from SAM, not from QC. Stop after one pass so a run always finishes.

Pipeline, API and the live UI

pipeline.py is the only file that knows the stage order. It emits progress events that the API streams to the browser over Server-Sent Events. That stream is what turns a 60-second wait into the best part of the demo.

scenecraft/pipeline.pypython · asyncio
import asyncio
from scenecraft import ingest, spotting, tracking, sync, sourcing, mix, qc

async def run(take_path, emit):
    """emit(event) must be thread-safe: api.py wraps queue.put_nowait in loop.call_soon_threadsafe."""
    clip = await asyncio.to_thread(ingest.prepare, take_path)
    emit({"stage": "spotting", "status": "running"})
    spot = await asyncio.to_thread(spotting.spot, clip.muse_path)
    emit({"stage": "spotting", "status": "done", "data": spot})

    sam_file = await asyncio.to_thread(spotting.upload, clip.sam_path)
    on_line = lambda concept, line: emit({"stage": "tracking", "concept": concept, "line": line})
    sources = spot["sources"]
    tracks, takes, bed = await asyncio.gather(  # SAM and AudioGen do not depend on each other
        asyncio.gather(*[asyncio.to_thread(tracking.track, sam_file, s["sam_concept"], on_line)
                         for s in sources]),
        asyncio.gather(*[sourcing.source(s["sound_prompt"], s["mode"]) for s in sources]),
        sourcing.source(spot["scene"]["ambience_prompt"], "ambience", keep=1),
    )
    emit({"stage": "sourcing", "status": "done"})

    ids = [s["id"] for s in sources]
    cue = sync.build_cue_sheet(clip, spot, dict(zip(ids, tracks)))
    emit({"stage": "sync", "status": "done", "data": cue})
    out = await asyncio.to_thread(mix.render_clip, clip, cue, dict(zip(ids, takes)), bed[0])
    emit({"stage": "mix", "status": "done", "url": out.url})
    cue = await qc.review_and_fix(clip, cue, out, emit)
    emit({"stage": "done", "data": cue})

API (api.py, FastAPI): POST /api/jobs takes the upload and starts run as a task; GET /api/jobs/{id}/events streams events with sse-starlette; GET /api/jobs/{id}/files/… serves the mp4, stems and cue sheet.
