# Clips

Film six 5-10s clips yourselves here (landscape, tripod or steady hands, good light),
per the build plan's `#spikes` section:

- `gravel.mov` — walking on gravel (the clip every code sample in this repo assumes)
- `wood_floor.mov` — walking on a wooden floor
- `door_slam.mov` — door open and slam
- `mug_set_down.mov` — mug set down and stirred
- `keys_drop.mov` — keys dropped on a table
- `jacket_zip.mov` — jacket zip
- `finale.mov` — one harder clip with two sources at once

Only use footage you shot yourselves — no film, TV, or copyrighted music, per the
build plan's asset rules (`#spikes`, `#risks`).

`app.py`'s `EXAMPLES` list points at three of these by filename — update it once
you've filmed and picked your three best.
